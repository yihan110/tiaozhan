# ruanyihan_C10H cron 定时任务示例

> 作者：阮依涵（ruanyihan）
> 依据：官方文档"定时自动化 / 内置 cron，可向任意平台投递"，以及社区资料中关于 gateway daemon 的说明。

---

## 1. Hermes 的 cron 是怎么工作的

- Hermes **内置 cron 调度器**，由常驻的 **gateway daemon** 驱动，大约每 **60 秒** tick 一次，到点就**在隔离会话里**跑该跑的任务，再把结果投递到你指定的平台（CLI / Telegram / 等）。
- **任务跨重启存活**：电脑/WSL 重启后，到点照样触发，不丢。
- **自然语言调度**：Hermes 的一个特点是——你**不一定非得手写 cron 表达式**，可以直接用自然语言描述"每天晚上 9 点提醒我……"，它帮你转成定时任务。（社区原话："You don't write cron expressions; you describe what you want in English and Hermes converts it."）
- 前提：要让 gateway 常驻运行（消息平台/gateway daemon 起着，cron 才会在后台 tick）。

## 2. 示例一（主推）：每天早上的四级词汇 + 今日待办摘要

**需求**：每天早上 8:00，让 Hermes 自动给她发一段：10 个四级高频词（带例句）+ 从她对话/记忆里攒下的今日待办提醒。投递到 Telegram（或 CLI）。

### 2.1 配置方式 A：自然语言（推荐，最省事）

在 Hermes 对话里直接说：

```
帮我建一个每天早上 8:00 的定时任务：每天给我出 10 个英语四级高频词汇，
每个词配一句简单例句，并顺带总结一下我最近交代给你的待办事项。
投递到 Telegram。把这个设成循环任务。
```

Hermes 会把它转成一个 cron job 并确认。

### 2.2 配置方式 B：等价的 cron 表达式（若要手动写）

| 字段 | 值 | 含义 |
|---|---|---|
| 分 | `0` | 第 0 分 |
| 时 | `8` | 早 8 点（按 Hermes 所在机器时区） |
| 日 | `*` | 每天 |
| 月 | `*` | 每月 |
| 周 | `*` | 不限星期 |

表达式：`0 8 * * *`

可读为："每 天 早 上 8:00:00"。

### 2.3 任务体（它到点执行的内容，可在 prompt 里写死）

```
请执行每日学习摘要：
1. 出 10 个英语四级高频词，每个词给词性、中文释义、一句简单英文例句。
2. 回顾你记忆里关于我（阮依涵）的待办，列出今天该推进的最多 3 件事（专业课/四级/社团/竞赛）。
3. 语气务实、去 AI 味，别灌鸡汤。
```

## 3. cron 表达式速查（自己写时对照）

格式：`分 时 日 月 周`（5 段）

| 想表达 | 表达式 |
|---|---|
| 每天早 8 点 | `0 8 * * *` |
| 每天晚 9 点（复习提醒） | `0 21 * * *` |
| 每周一早 9 点（社团周计划） | `0 9 * * 1` |
| 每小时整点 | `0 * * * *` |
| 每天 9:00 和 21:00 各一次 | `0 9,21 * * *` |
| 工作日（周一到周五）早 7:30 | `30 7 * * 1-5` |

> ⚠️ 时区以 WSL2 里系统时区为准（国内一般是 CST/UTC+8）。如果发现它在错误的时间触发，先 `date` 看 WSL 里的时区对不对。

## 4. 示例二：每天晚 9 点的"今日复盘 + 明日待办"

```
帮我建一个每天晚上 9:00 的循环定时任务：用三句话总结今天我让你做过的事，
再列出明天我最该先干的 1 件事。发回 Telegram。
```
对应表达式：`0 21 * * *`。

## 5. 管理与验证 cron 任务（装好后照做）

```bash
# 查看当前有哪些定时任务（具体子命令以 hermes 版本帮助为准）
hermes cron list
# 在对话里也能查
/cron
```

**验证它真的会跑**：
1. 先建一个"1 分钟后触发"的测试任务（`*/1 * * * *` 或直接说"1 分钟后提醒我测试"）。
2. 确认 gateway 在跑、到点真的收到消息。
3. 确认重启 WSL 后任务还在（`wsl --shutdown` 再开，等下一个整点看是否触发）。

**常见坑**：
- 到点不触发 → gateway daemon 没在后台跑；把 `hermes gateway` 保持运行（或设成开机自启）。
- 时间不对 → WSL 时区/时钟问题，`date` 核对。
- 想投递到 Telegram 但没配好 token → 先 `hermes gateway setup` 配好平台。

> 说明：以上为**真实可用的 cron 配置示例与表达式讲解**，尚未在本机真实触发（本机无 WSL2、无 gateway、无 API Key）。装好 WSL2 与 Key 后，用第 2.1 节那句自然语言即可一键建成。
