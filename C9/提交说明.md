## 二、MVP 在本机真实运行了什么（证据）
运行时间：2026-11-01 07:04（见各运行记录文件头）。解释器：本机 Python 3.13.16。
1. `add` × 5：录入 2 张高数、2 张四级、1 张数据结构卡片 → 见 `运行记录/01`
2. `due`：列出 5 张今日到期卡片 → 见 `运行记录/02`
3. `review` × 5：分别给 good / again / good / easy / good，系统自动算出下次到期日（again 那张 ease 从 2.5 掉到 2.3、easy 那张升到 2.65）→ 见 `运行记录/03`
4. 复习后 `due`：今日清零 → 见 `运行记录/04`
5. `--today 2026-11-05 due`：模拟未来日期，验证间隔重复排期生效（到期卡片重新出现、逾期标记）→ 见 `运行记录/05`
6. `stats` + `list`：统计（5 卡 / 累计复习 5 次 / 标签分布）与全量列表 → 见 `运行记录/06`
