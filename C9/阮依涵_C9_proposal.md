## 1. 项目定义（Project Definition）

- **我想做什么（一句话）**：做一个跑在自己电脑命令行里的「间隔重复复习小工具」，把我平时整理的高数错题、四级单词、专业课知识点，按遗忘曲线每天只推到期的几张，复习完即走，解决"整理完就再也不看"的问题。

- **输入**：我自己随手记的卡片——正面是问题/题干（比如"二重积分交换积分次序的前提条件"），背面是答案/解析/高频替换词，外加一个学科标签（高数 / 四级 / 数据结构）。

- **输出**：
  1. 每天一份"今日待复习清单"（只列今天真该看的，不堆量）；
  2. 每次复习后的评分记录与下次到期日；
  3. 一张简单的统计（卡片总数、今日到期、累计复习次数、标签分布）。

- **为什么这件事重要**：
  - **对我**：我这学期真实的痛——四级刚考完感觉不理想、高数刚学完二重积分但一合书就忘、错题 OCR 整理了一堆文件躺在文件夹里再也没打开过。我的问题不是"不会整理"，而是"没有一个系统逼我按记忆曲线回头看"。这个工具先服务我自己。
  - **对他人 / 对世界**：同类大学生（尤其工科、要考公/考研/刷四级的）大概率有一模一样的痛。如果我自己用顺了，可以开源到 GitHub，给同学一个不用装 Anki、不用注册、双击就能跑的轻量替代。

- **这个东西目前存在吗**：
  - **存在，而且很强**——Anki 就是这个领域的天花板，开源、SM-2 算法原教旨实现。
  - **我的版本有什么不同**：
    1. Anki 太重、界面劝退，我想要的是"命令行里 30 秒扫完今日卡片"，打开终端就复习，不离开写代码的环境；
    2. 我不做插件市场、不同步、不做富媒体，**只解决"工科生每天 10 分钟复盘"这一个最小闭环**；
    3. 数据就是一个本地 JSON 文件，我这个软件工程学生能完全看懂、随时改、随时备份，没有任何锁定。
  - **为什么之前没人做（我凭什么能做成）**：不是没人做，是做得太重。Anki 面向全球所有学习者，功能大而全；但我要的是"一个只属于我这台电脑、零配置、和我写代码的终端长在一起"的版本。这种"小到不值得商业公司做"的工具，恰恰是个人项目最该占的位置——**市场小，但我自己就是第一个真实用户，我不靠它赚钱，靠它把自己的复习习惯跑起来。**

## 2. 拿来主义分析

### 竞品 / 参考项目

| 名称 | 链接 | 它做了什么 | 它做得好的地方 | 它做得不好的地方 |
|------|------|-----------|--------------|----------------|
| **Anki** | https://apps.ankiweb.net/ ｜ https://github.com/ankitects/anki | 开源间隔重复记忆软件，SM-2 算法，跨平台同步 | 算法经过 20 年验证；社区卡片库极大；完全免费 | 桌面端界面老旧、配置项极多，新手打开就懵；我只想每天看 5 张，它却逼我建牌组、调选项、装插件 |
| **墨墨背单词** | 手机 App | 面向英语单词的间隔重复 App | 算法顺滑、每天只推推荐量、提醒到位 | 只做单词、绑定云端、要花钱买上限；高数错题/专业课根本用不了 |
| **Notion 数据库** | https://www.notion.so/ | 用表格 + 日历属性自己搭复习台账 | 灵活、能写富文本 | 没有真正的间隔重复算法，到期日要自己算、自己手改；联网才好用，校园网/断网就废 |
| **Quizlet** | https://quizlet.com/ | 闪卡 + 学习模式 | 制作卡片简单、游戏化 | 免费版广告多、间隔重复是付费功能；国内访问慢 |

### 我拿来的部分（Adopted）

- **从 Anki 拿了**：SM-2 间隔重复算法的核心思想——按"again/hard/good/easy"四档评分，答对就拉长下次间隔、答错就打回 1 天重学、易度系数（ease factor）随表现微调。**为什么好用**：这是被几十年实证验证过的抗遗忘机制，我没必要自己发明轮子，直接拿来用，但做了简化（见下）。
- **从墨墨背单词拿了**："每天只推今天该看的量，不列全部卡片"的产品思路。**为什么好用**：避免一打开看到几百张卡片直接劝退，降低每天的启动阻力。
- **从 Notion 台账思路拿了**：一条卡片 = 一行结构化数据（正面/背面/标签/到期日/复习历史）。**为什么好用**：让数据和展示分离，我以后想加 HTML 页面、想加统计图表，都是读同一个 JSON。

### 我不要的部分（Removed）

- **Anki 的牌组/子牌组/标签层级/插件系统我不要**，因为：我一个人用、一共就高数/四级/数据结构三个学科，一层 tag 足够，多了就是负担。
- **墨墨的云端账号 + 付费上限我不要**，因为：数据放我自己电脑一个 JSON，零成本、零锁定、断网能用。
- **Quizlet 的游戏化/配对/拼写小游戏我不要**，因为：我要的是"快速过一遍想没想起来"，不是玩游戏，游戏反而拖慢每天 10 分钟的节奏。

### 我的差异化（Improved / 核心差异）

- **核心差异**：把"间隔重复"从一个 App 降级成**一个终端命令**——`due` 列出今天该看什么，`review <id> good` 一秒评分，和我平时写代码、跑作业的环境完全打通。不用切软件、不用扫码登录、不用等启动。
- **为什么有价值**：对我这种每天本来就要开好几次终端写 Python/跑 Linux 实验的人，"复习"不再是一件需要专门打开一个 App 去做的事，而是变成终端里一行命令。** friction（启动阻力）从"打开一个 App"降到"敲两个词"**，这是我这个真实用户最在意的点。

## 3. 自驱动机制（Motivation System）★ C9 独有重点

> 这是整个项目我想得最久的部分。因为 C9 没有导师、没有 deadline、没有同桌，**最大的风险不是做不出来，是第三周就忘了这个文件夹存在**。下面每一条都是我作为一个软件工程大一学生，真的能执行的动作，不是口号。

### 3.1 为什么我会持续做这个项目

- **兴趣 / 好奇心**：我本身就喜欢"用代码解决自己生活里的小破事"。看着自己写的脚本真的帮我复习了一个四级单词、真的在我没记住一道高数题时第二天又把它推到我脸上，这种"自己造的工具反过来管我"的感觉很好玩。
- **现实收益**：这个项目一箭三雕——① 直接服务我的高数/四级复习，期末和四级出分就是最硬的验收；② 代码本身写的是 CLI + 文件读写 + 调度逻辑，是软件工程的硬技能，能放进我的 GitHub（联动 C5）；③ 我在无人机社团本来就常写小工具，这套"把重复劳动脚本化"的思路以后能复用。
- **身份认同**：我想成为那种"遇到一个低效的破习惯，不抱怨，而是写个小工具把它修掉"的人。不是"我正在做一个叫 StudyLoop 的作业"，而是**"我是一个用工程手段管理自己学习节奏的人"**。这是第三层动力，最持久。

### 3.2 如果没人监督，我如何保证推进

**固定节奏（具体到星期几几点）**：
- **每周三、周日 晚 21:30–22:00**：这是我雷打不动没课、也通常没社团事的时段。每周两次，每次 30 分钟，到点就开终端。
- **每天 22:00 睡前 3 分钟**：只做一件事——跑 `due`，把今天到期的卡片过一遍。这是"最低标准"，不算开发时间，算使用时间。

**触发器（什么事件提醒我开始）**：
- 手机闹钟两个：**21:30「StudyLoop 开发时间」**、**22:00「今日 due 了吗」**。闹钟标题直接写动作，不写模糊的"学习"。
- 物理触发器：把"打开终端"这个动作和我每晚必做的"插手机充电"绑定——手机一插上，终端就开。行为设计里叫习惯叠加（habit stacking）。

**反馈回路（怎么看到进展、怎么自我激励）**：
- 每跑一次 `stats`，就能看到"卡片总数 / 累计复习次数"在涨——数字本身就是正反馈。
- 每周日晚上记一笔：这周哪张卡片我连评了两次 again（说明真没懂），哪张 easy 一路升间隔——**看得见自己的记忆曲线在动**。
- 小奖励：每完成一个里程碑（见 3.4），允许自己那天多打 20 分钟游戏 / 喝一杯奶茶。奖励要小、要即时，不能等 8 周后。

**打卡 / 记录工具**：
- 不用新 App，就用仓库里一个 `打卡.md`，每周三、日各打一行：日期 + 今天做了啥（加了几张卡 / 改了哪个 bug / 复习了几次）。连续打卡自己能一眼看到。

**里程碑与对外承诺（防止缓慢放弃）**：
- **对外公开承诺**：代码放我自己的 GitHub 私有仓库，每周日把"本周做了什么 + 一张 `stats` 截图"发到 Elite20 群里。群里有人看，是最便宜的社会压力。
- **最低标准（最忙的一周也保底）**：哪怕这周考试周/社团忙到爆炸，我至少也做一件事——**跑一次 `due` 并复习完今日卡片**，不许连续 7 天零运行。工具不用，就等于这个项目死了。

**失败信号（提前定义"我已经放弃了"长什么样）**：
- 如果**连续 2 周** `打卡.md` 没有新增任何一行、且本机 `data/cards.json` 的复习记录（history）连续 14 天为空——说明我不是在做项目，是在写一份没人看的作业。
- 触发失败信号时的预设动作：**不是硬扛，而是降级**——停止加新功能，只保留"每天 due 复习"这一个动作，先把使用习惯续上；如果再降级一周还是零使用，就在 AAR 里诚实写"这个方向对我来说负担太重，需要换一个更小的切口"（允许换一次方向，但必须写清楚学到了什么）。

- **我可以拿来的现有资源**：Anki 开源代码里的 SM-2 实现做参考；CHALLENGE.md 本身给的 KSTAR/AAR 模板；我这学期高数、四级、数据结构的真实错题就是现成的卡片素材。

### S（Situation / Situation 现状与约束）

- **当前状态**：大一上，课业压力大（高数/线代/程序设计），无人机社团副社长占时间，刚考完四级等成绩。
- **约束**：

## 5. MVP（第一周产出）

- **我第一周做出来的东西**：一个能在本机真实运行的命令行复习工具 `阮依涵_C9_mvp.py`，已经录进 5 张我自己的真实卡片（2 张高数、2 张四级、1 张数据结构），走完了"添加→列出今日到期→逐张评分复习→看统计"完整闭环。
- **形态**：Python 代码（纯标准库，零第三方依赖）+ 本地 JSON 数据文件 + 6 份本机真实运行记录（终端输出留档）。
- **别人看了能理解什么**：看到 `due` 列出来今天该复习哪几张、给 `good` 之后系统自动把下次排到 1 天后、给 `again` 之后易度下降第二天再来——他就能懂"哦，这就是一个属于我自己的、极简版 Anki，而且真的在跑，不是 PPT"。
- **展示方式**：
  1. 直接 `python 阮依涵_C9_mvp.py due` 现场跑；
  2. 看 `mvp/运行记录/` 下 6 份带时间戳的真实终端输出；
  3. 打开 `mvp/data/cards.json` 看结构化数据。
- **MVP 验收标准（怎么算做成）**：
  - [x] 零依赖，`python 阮依涵_C9_mvp.py` 在干净环境能跑；
  - [x] add 能录卡、due 能列出今日到期、review 能按四档评分并改下次到期日、stats 能出统计；
  - [x] 用 `--today 2026-11-05 due` 模拟未来日期，能验证"到期卡片会重新出现"——证明间隔重复真的生效，不是写死的；
  - [x] 有真实运行记录，不是我嘴上说跑过。
