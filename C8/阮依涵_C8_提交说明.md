## 三、验证物在本机真实运行了什么

- **运行命令：** `python 阮依涵_C8_demo.py`（在 `demo/` 目录下）
- **运行环境：** Windows 11 + Python 3.13.16，零 `pip install`
- **运行结果：** 见 `demo/run_output.txt`，三个测试用例：
  1. 李先生报障 → 命中规则 A3（站点 DOWN）→ 根因 `site_outage` → 派赵工；
  2. 张女士（VIP）报障 → 命中规则 A4 → 升级 P1 → 因无 senior 工程师覆盖 → 待调度；
  3. 陌生人报障 → 图中无此客户 → 走 `transfer_to_human` 分支。
- **自检：** 退出码 0，无报错，输出与 `run_output.txt` 一致。

本提交包为**申请阶段**产物，以下环节**故意留空**，等入选后再补：

1. **LLM API Key**——demo 里的 Think 阶段目前是规则模板，
   入选后 W5–W6 才会接 LLM（NL2Think），届时需要导师提供 API 额度；
2. **Neo4j 环境**——demo 用内存图，入选后 W3–W4 迁到本地 Neo4j Desktop；
3. **真实业务术语表**——T-box 目前是我根据华为 ICT 背景自己拟的 6 类概念，
   需要导师/客户方提供脱敏术语表对齐；
4. **真实脱敏数据**——A-box 目前是 13 节点玩具数据，
   入选后需客户提供 50–100 条脱敏样本。

这些不是"漏做"，是 Proposal R̂ 里明确写的 W1–W8 计划。
