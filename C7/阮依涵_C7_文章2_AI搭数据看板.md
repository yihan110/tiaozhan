## 一、开头：老师说"做个网页展示数据"，我人傻了

大一上学期，一门课的大作业要求：**做一个网页，把一组数据用图表展示出来。**

我当时的水平：HTML 标签刚认全，CSS 只会写"红色居中"，JavaScript 一行没碰过。

离交作业还有一周。我没有去报班，也没有熬夜啃教程——我做了一件现在看来很对的事：**把需求直接讲给 AI 听，让它带我一行一行写。**

一周后，我真的交出了一个能打开、有图表、能切换数据的网页。这篇文章记录全过程，特别是我踩过的 5 个坑。

## 二、背景：为什么是"数据看板"这个小项目

我选的数据看板不是什么宏大系统，就是一个很朴素的东西：

- 顶部：一个标题和更新日期；
- 中间：2–3 张图表（折线图看趋势、柱状图看对比）；
- 底部：几个数字卡片（总数、平均值）。

**为什么推荐新手从这种小项目入手？** 因为它刚好卡在"够得着"和"有成就感"之间：组件少，AI 一次能讲清楚；做完之后又确实像个"作品"，能写进简历那种。

---

## 三、过程：我是怎么一步步做出来的

### 第 1 步：先让 AI 给我"画地图"，而不是直接写代码

我的第一个 prompt 不是"帮我写个网页"，而是：

```text
我是软件工程大一学生，只会一点 HTML/CSS，
JavaScript 几乎零基础。我要做一个课程成绩数据看板网页，
包含：1个标题、3张图表、3个数字卡片。
请先不要写代码，先用中文告诉我：
这个网页需要几个文件？每个文件干什么？
图表用什么库？大概的开发顺序是什么？
```

**这一步非常关键。** 它让我在动手前先知道"自己在做什么"，而不是对着一堆看不懂的代码发呆。AI 给我的回答是：一个 `index.html`、一个 `style.css`、一个 `app.js`，图表用 Chart.js（一个 CDN 引入就能用的轻量库）。

### 第 2 步：一个组件一个组件地来，不贪多

我没有一次要"把整个网页写完"，而是**一次只让 AI 写一个组件**：

```text
现在我只做最上面的标题栏：
深色背景(#1e1e2e)、白色标题、右上角显示今天日期。
请给我对应的 HTML 和 CSS，并逐行解释这段代码什么意思。
```

写完一个，我就去浏览器里刷新看效果。**看到东西变出来的那一下，是坚持下去的动力。**

### 第 3 步：图表用 CDN 引入，不自己装环境

新手最容易在"搭环境"上卡死。我的做法是：直接在 HTML 里写一行 CDN：

```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```

这样不用 npm、不用安装、不用配路径，**打开浏览器就能用图表库**。对课设这种小作业，这是最省力的路。

### 第 4 步：数据先写死在代码里，别一上来接后端

我一开始想做"能实时填数据"的版本，被 AI 劝退了：

> 配图建议 2（放在此处）：AI 建议截图——"新手第一版先把数据写成 JS 数组，跑通页面后再考虑输入框"，旁边打个对勾。

我的做法：

```javascript
const scores = [
  { name: '高数', score: 92 },
  { name: '英语', score: 88 },
  { name: '软工导论', score: 95 }
];
```

**先把页面做"死"，再想办法做"活"。** 这是我这一周学到的最重要的工程思维。

### 第 5 步：出错了，把报错原文整段贴给 AI

中间我大概报错了十几次。我的诀窍是：**不要自己描述"好像不行"，直接把浏览器控制台里的红色报错整段复制给 AI**：

```text
我运行这段 JS 后控制台报这个错：
[粘贴完整报错，包括文件名和行号]
我贴一下我的代码：[粘贴]
请告诉我错在哪、怎么改，为什么。
```

比"它不工作了"有效一百倍。

## 四、结果：一周后我交出了什么

- 一个 `index.html` + `style.css` + `app.js` 的小项目，**双击就能在浏览器打开**；
- 3 张 Chart.js 图表正常渲染，数字卡片会随数据变化；
- 我能对着老师讲清楚"每一行代码大概在干嘛"——这比"能跑"重要，因为答辩要问。

坦白说，这个网页放到 GitHub 上只是个小练习，**不是什么拿得出手的产品**。但对一个大一、只会 HTML 皮毛的人来说，它证明了一件事：**我可以用 AI 当老师，真的从 0 做出一个完整的小东西。**

---

## 五、避坑：5 个坑，我先替你踩了

1. **别一上来就要"完整代码"**——你看不懂，改不动，最后变成一坨谁也不认识的文件；
2. **别在环境配置上死磕**——课设用 CDN 就够了，npm 以后再学；
3. **别跳过"逐行解释"**——让 AI 解释代码不是浪费时间，是你唯一能学会的方式；
4. **数据先写死**——"能输入数据"是第二版的事，第一版先让图表亮起来；
5. **别只说"报错了"**——把完整报错和代码一起贴，AI 才能真正帮到你。

AI 不会替你交作业，但它会在你每一次想放弃的时候，给你一段能跑的代码、一句能懂的解释。
