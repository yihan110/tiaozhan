# 代码/配置排错工作流

## What（做什么）
遇到代码报错或竞赛配置排错时，按固定流程排查，避免靠感觉瞎试。

## When to Use（什么时候用）
Python 作业报错、网络设备配置不通、竞赛模拟题排错。

## Input（输入）
- 完整报错信息（不要截一半）
- 最近改过什么
- 期望 vs 实际

## Steps（步骤）
1. 把报错最后 5 行完整复制，不要只看第一行。
2. 问自己：期望是什么？实际是什么？一句话写下来。
3. 用排除法：注释掉一半代码看是否还报错。
4. 如果是配置类（如 OSPF/ACL），拉一张核对表，每条规则单独打勾。
5. 修完后必须写一行注释说明这次为什么错。
6. 同类错误第二次出现，加到本 Skill 的'常见坑'清单。

## Tools（需要什么工具）
VSCode；Python；DeepSeek（解释报错）。

## Output（输出）
修复后的代码 + 一行注释说明根因 + （可选）追加到常见坑清单。
