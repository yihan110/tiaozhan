# 阮依涵 C6 Repo 链接

> ✅ **已推送到 GitHub**。

## 推送命令（Windows PowerShell）

```powershell
cd app
git init
git add .
git commit -m "init: 文枢 AI v1.0"
git branch -M main
git remote add origin https://github.com/yihan110/tiaozhan.git
git push -u origin main
```

## 填写

```
GitHub repo URL：https://github.com/yihan110/tiaozhan/tree/main/C6/app
```

## 注意

- 🔐 **不要**把 `.env` 或任何含真实 Key 的文件 commit 进去。
- `.gitignore` 建议至少包含：`.env`、`__pycache__/`、`*.pyc`、`.venv/`。
- 本包 `app/` 目录即完整 repo 内容，直接 `git init` 即可。
