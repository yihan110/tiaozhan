# 阮依涵 C6 AI 使用日志

> 所有 prompt 都是实际对 AI 说过的话（整理后），不是事后编造。

## 阶段 0：产品定位（决策）

**Prompt 1：**
> 我是郑州西亚斯学院软件工程大二学生，要做一个 C6 Web App，AI 必须是核心功能。我平时常写的东西是：简历经历、竞赛申报材料、自荐信、课程论文。帮我想一个"别人打开就想用"的小工具，不要太复杂，2-4 小时能做完。

**AI 回答要点：**
- 别做"聊天机器人"——太多人做了，没差异化。
- 做"输入一段你的真实文字 → AI 当场诊断打分 + 给改写方向"。
- 切 4 个具体模式：简历 / 文书 / 竞赛材料 / 长文档摘要。
- 关键卖点：**不注册、打开就能用、本地演示模式也能跑**。

**我的判断：** 采纳。理由是这正好对应我自己的真实痛点，写出来的 prompt 才不会飘。

## 阶段 1：技术选型

**Prompt 2：**
> 前端用什么？我要响应式、好看、不用写 CSS。
> 后端我想选 Flask（比 FastAPI 熟）。
> AI 调用怎么设计才安全？不能把 Key 写死在前端。

**AI 回答要点：**
- 前端：单页 HTML + Tailwind CDN，不引入 React 构建链，部署最简单。
- 后端：Flask，一个 `app.py` + 一个 `ai_service.py` 就够。
- Key 安全：① 服务器端环境变量 `OPENAI_API_KEY`；② 前端高级选项允许用户临时填自己的 Key，只随请求发一次，不落库。
- **必须有 mock 模式**：没 Key 时用本地规则引擎顶上去，否则评委打开就是报错。

**我的判断：** 全采纳。这一阶段定下来的结构直接影响后面代码。

## 阶段 2：骨架生成（第一次写代码）

**Prompt 3：**
> 帮我生成 Flask 项目骨架：
> - `app.py`：路由 `/`、`/api/health`、`POST /api/analyze`
> - `config.py`：全部走环境变量
> - `ai_service.py`：暴露 `MODES` 字典和 `analyze(text, mode, api_key)` 函数
> - 没 Key 时返回 mock 结果，结构里要有 `ai_mode` 字段标 "mock"
> 不要写真正的 mock 内容，先把函数签名和异常处理搭好。

**AI 产出：** 完整骨架，含 `requests.RequestException` 捕获、8000 字上限、mode 白名单校验。

**我的改动：**
- 把 `MODES` 从硬编码 dict 改成带 `label` + `hint` 的结构，前端直接渲染 tab 和提示。
- 加了 `/api/health`，方便部署后探活。

## 阶段 3：mock 引擎（关键——不能是假 AI）

**Prompt 4：**
> 我要做一个本地规则引擎当 mock，不能写死模板字符串骗人。
> 输入中文文本，输出：
> 1) 句子数、字符数
> 2) 关键词抽取（中文 2-4 字片段 + 英文单词，去停用词）
> 3) 结构识别：有没有 bullet、有没有分段
> 4) 四维打分（长度 / 结构 / 简洁 / 行动词密度），规则透明
> 5) 根据上面这些统计结果动态生成建议
> 用 Python 写。

**AI 产出：** 正则切句、`re.findall(r"[一-龥]{2,4}|[A-Za-z]...")` 抽词、加权打分。

**我自己 debug 的地方：**
- **Bug 1**：关键词抽取把"的了和"都抽出来了 → 加停用词表。
- **Bug 2**：长词包含短词（"无人机"和"机社团"）重复 → 加了"包含关系去重"逻辑。
- **Bug 3**：建议太笼统 → 改成根据真实统计触发：
  - 检测不到 `\d` → 提示"缺量化数据"
  - 检测不到动词词表（完成/实现/主导…）→ 提示"缺动词开头"
  - 平均句长 > 80 → 提示"句子偏长"

## 阶段 5：本机运行 & 排错（真实 debug）

**问题 1：** `python app.py` 报 `ModuleNotFoundError: flask`。
> 排查：`pip3 install` 装到了别的 Python，当前 `python` 是 `D:\01python\python.exe`。
> 解决：改用 `python -m pip install flask requests`，立刻生效。
> 教训：Windows 上多 Python 环境，永远用 `python -m pip`。

**问题 2：** 健康检查 `http://127.0.0.1:5050/api/health` 连接被拒。
> 排查：app 还没起来就发请求了，加 `Start-Sleep 3` 再测。
> 之后跑通：`{"ok":true,"real_ai_configured":false,"version":"1.0.0"}`。

**问题 3：** Edge headless 截图第一次没出图。
> 原因：老版 `--headless` 参数在新 Edge 上行为变了。
> 解决：改用 `--headless=new --user-data-dir=临时目录 --virtual-time-budget=5000`，第二次出图。
