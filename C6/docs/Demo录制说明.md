# Demo 视频录制说明

> 目标：录一段 **30-60 秒** 的演示视频，让没见过这个 App 的人 10 秒内懂它是干什么的。

---

## 一、用什么工具

| 工具 | 适合谁 | 备注 |
|---|---|---|
| **Windows 自带 Xbox Game Bar**（`Win + G`） | 最简单 | 直接录屏，导出 mp4 |
| **OBS Studio**（免费） | 想要高质量 | 可同时录摄像头 + 屏幕 |
| **剪映** | 需要后期加字幕 | 录完后裁剪、加文字 |

推荐：先用 `Win + G` 录，不够再上 OBS。

---

## 二、录哪些操作（脚本）

按这个顺序，别乱：

```
0-5 秒   浏览器打开公网 URL（或 http://127.0.0.1:5000）
         口述："这是文枢 AI，输入一段你的文字，AI 当场给你诊断打分。"

5-15 秒  切换到"简历/经历优化"tab
         口述："比如我把我的简历经历贴进来——"
         粘贴一段真实文本（用样例：无人机社团副社长那段）

15-30 秒 点"开始 AI 分析"
         口述："点一下，右侧立刻出四维打分、关键词、改写建议。"
         （等结果出来，让分数条停 2 秒）

30-45 秒 再切到"长文档摘要"模式，贴一段短文本，再点一次分析
         口述："换个模式也行，长文档摘要、文书润色、竞赛材料整理都支持。"

45-60 秒 结尾："配置自己的 AI Key 就能切到真实大模型分析，
         本地演示模式也能跑。链接放评论区，大家试试。"
```

---

## 三、注意事项

- 🔐 **录之前清掉敏感信息**：API Key、学号、手机号、家庭住址都别出现在画面里。
- 用 Edge headless 已经截好的两张图在 `screenshots/`，录屏前可以先打开看一下效果。
- 麦克风安静一点，别开风扇。
- 导出 **mp4**，文件名：`阮依涵_C6_demo.mp4`。
- 时长卡在 60 秒以内——评委没耐心看 3 分钟。
