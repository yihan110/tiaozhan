# 部署说明（文枢 AI）

> 目标：把本项目从"本地能跑"变成"任何人打开链接就能用"。
> 标 🔐 的步骤需要**你本人的账号**，AI 执行者无法代办。

---

## 方案 A：本地运行（已验证）

```powershell
cd app
python -m pip install -r requirements.txt

# （可选）配置真实 AI Key
$env:OPENAI_API_KEY = "sk-..."
$env:OPENAI_BASE_URL = "https://api.openai.com/v1"
$env:OPENAI_MODEL = "gpt-4o-mini"

python app.py
# 浏览器打开 http://127.0.0.1:5000
```

验证：
- 打开 `http://127.0.0.1:5000/api/health` 应返回 `{"ok":true,...}`
- 首页右上角显示"本地演示模式"或"真实 AI 已启用"

## 方案 B：部署到 Vercel（推荐，免费）

> 因为是 Flask（有后端），Vercel 需要一个 `api/` 入口 + 一个静态前端。
> 最省事的做法是**把 Flask app 当作一个 serverless 函数**。

### 步骤

1. 🔐 **注册 GitHub 账号**（如果还没有）：https://github.com
2. 把 `app/` 目录下所有代码推到一个新 repo：
   ```powershell
   cd app
   git init
   git add .
   git commit -m "init: 文枢 AI v1.0"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/wenshu-ai.git
   git push -u origin main
   ```
3. 🔐 **注册 Vercel 账号**：https://vercel.com （用 GitHub 登录一键授权）
4. Vercel 首页 → **Add New Project** → 选中刚推的 repo → **Import**
5. Vercel 会自动识别。如果是 Flask，需要加一个 `vercel.json`：
   ```json
   {
     "version": 2,
     "builds": [{ "src": "app.py", "use": "@vercel/python" }],
     "routes": [{ "src": "/(.*)", "dest": "app.py" }]
   }
   ```
6. **Environment Variables**（在 Vercel 项目 Settings 里加，不要写进代码）：
   - `OPENAI_API_KEY` = 🔐 你自己的 Key
   - `OPENAI_BASE_URL` = `https://api.openai.com/v1`（或 DeepSeek / 通义等）
   - `OPENAI_MODEL` = `gpt-4o-mini`
7. 点 **Deploy**，等 1-2 分钟，拿到 `https://wenshu-ai-xxxx.vercel.app`
8. 把这个 URL 填进根目录的 `阮依涵_C6_app链接.md`

### 注意

- 🔐 **绝对不要**把 `OPENAI_API_KEY` 提交到 GitHub。`.env` 文件不要 commit。
- Vercel 免费层有请求次数限制，demo 够用。
- Flask 在 serverless 模式下是无状态的，本项目本来就无状态，正好适配。

## 方案 C：Render / Railway（备选，适合常驻后端）

如果 Vercel 的 serverless 对你来说太绕，可以用 Render 免费层：

1. 🔐 注册 https://render.com
2. New → Web Service → 连 GitHub repo
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python app.py`
5. Environment Variables 同方案 B 第 6 步
6. 拿到 `https://wenshu-ai.onrender.com`（免费层会冷启动，第一次打开要等 ~30 秒）

## 方案 D：纯本地暴露给同学临时用（不推荐但能用）

如果就是想发到群里让同学点一下看效果：

```powershell
# 用 ngrok 或 cloudflared 把本地 5000 端口暴露出去
# 🔐 需要你自己去 ngrok.com 注册拿 authtoken
ngrok http 5000
# 会拿到一个 https://xxxx.ngrok.io 临时链接，关掉终端就失效
```

## 部署后必做的 3 件事

1. **手机打开 URL**：确认响应式布局没崩（CHALLENGE.md 要求）。
2. **不登录直接用**：清掉浏览器缓存，不登录任何账号，走一遍"输入→分析→出结果"。
3. **截图**：把公网 URL 页面再截一张图，替换 `screenshots/` 里的本地截图（或并存）。
