# 提交流程说明（C6 Web Application）

> 按 CHALLENGE.md 第十二节「提交内容」表逐项对齐。

---

## 一、需要提交的 5 样东西

| # | 文件 | 命名 | 状态 |
|---|---|---|---|
| 1 | 可访问网址 | `阮依涵_C6_app链接.md` | ⏳ 部署后由本人填 URL |
| 2 | Demo 视频 | `阮依涵_C6_demo.mp4` | ⏳ 本人按 `docs/Demo录制说明.md` 录 |
| 3 | GitHub repo | `阮依涵_C6_repo链接.md` | ⏳ 本人推到 GitHub 后填 |
| 4 | AI 日志 | `阮依涵_C6_AI日志.md` | ✅ 已交付 |
| 5 | 拿来说明 | `阮依涵_C6_拿来说明.md` | ✅ 已交付 |

外加本包附带的：`README.md`、`阮依涵_C6_AAR.md`、完整代码、本机截图。

---

## 二、提交前 Checklist（对照 CHALLENGE.md 第十四节）

- [ ] URL 可公开访问（不需要登录我的开发环境）
- [ ] 30 秒内能看懂这个 App 是干什么的
- [ ] 核心功能可用（输入 → 处理 → 输出，完整走通）
- [ ] AI 是核心功能的一部分（不是点缀）
- [ ] 手机浏览器上基本可用
- [ ] API Key 没有暴露在前端代码里
- [ ] 有 Demo 视频或截图
- [ ] 有 AI_LOG.md
- [ ] 有 ATTRIBUTION.md
- [ ] 群内已分享链接并邀请试用

## 四、本人还需要做的事（按顺序）

1. **推 GitHub**：按 `docs/部署说明.md` 方案 B 第 2 步。
2. **部署 Vercel**：按方案 B 第 3-7 步，拿到公网 URL。
3. **填 URL**：把 URL 写进 `阮依涵_C6_app链接.md`。
4. **填 repo 链接**：写进 `阮依涵_C6_repo链接.md`。
5. **录 demo**：按 `docs/Demo录制说明.md`，导出 `阮依涵_C6_demo.mp4`。
6. **手机打开公网 URL 验证一次**，截图存进 `screenshots/`。
7. **发到群里**，附上面那段话术。
8. **观察反馈**：谁用了、停留多久、有没有回来再用——记到 AAR 的 v2 里。
